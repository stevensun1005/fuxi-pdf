# 笔记模式与模板

根据明确请求使用相关模式，不要求普通复习任务选择全部模式。

| 模式 | 模块结构 |
| --- | --- |
| 章节笔记 | 概念引入、核心公式、方法速通、典型示例、真题/实战、巩固练习、总结复盘 |
| 期末冲刺 | 考法、真题来源与年份、方法、讲解例题、留白练习；答案独立 |
| 考研 | 七步结构、已核实的院校/年份/题号、每编题型专项总结 |
| 考公 | 行测/申论/面试模块、考点、方法/框架、真题、练习；时政标日期与来源 |
| 科研 | 背景、方法、结果、创新、局限、与用户研究的关系（仅有上下文时判断）；完整文献信息 |
| 项目 | 目标、架构、模块、真实进度、问题与决策、复盘；不编造负责人或完成状态 |

## 随附模板

- [LaTeX 完整模板](../assets/latex/template.tex) 与 [导言区](../assets/latex/preamble.tex)：同目录复制后修改；不与另一套导言区直接堆叠，避免命令冲突。
- [简洁复习 LaTeX](../assets/review-template.tex)：可作为完整复习包的起点。
- [Typst 完整模板](../assets/typst/template.typ) 与 [样式](../assets/typst/preamble.typ)：保持相对导入可解析。
- Markdown：[章节](../assets/markdown/chapter-notes.md)、[期末](../assets/markdown/exam-review.md)、[科研](../assets/markdown/research-note.md)、[项目](../assets/markdown/project-summary.md)。

模板为上游原始素材，使用前替换所有示例与占位内容，不把示例身份当成作者。检查实际字体；默认 SimSun 不存在时选择支持中文的已安装字体。模板编译能力需在生成任务中验证，此技能安装本身不代表模板已在当前机器编译通过。

单栏、可读字号、克制语义配色；公式框不应压缩长公式。超宽表格拆分或换行。保留修改日期，中文文档可用 `YYYY年M月D日`，年份来源于当前任务时间。

使用 TikZ 箭头标签时，随附样式 `alabel`、`alabel above`、`alabel below` 可避免与目标重叠，仍须在成品中实际检查。示意图保持可复现；不足以确认图形含义时回原页核对。
