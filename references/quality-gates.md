# 交付前核验

只检查当前请求适用的项，不以清单扩张范围。记录证据，未解决项不能被 PASS 掩盖。

| 检查 | 要证明的事实 |
| --- | --- |
| 来源顺序 | 文件齐全，读出真实页数，讲次顺序有依据。 |
| 页覆盖 | 台账集合等于每个来源的 1 到末页；跳过有理由，无 uncertain。 |
| 深度 | 核心概念有机制、条件、例子与区别，不只列术语。 |
| 考核证据 | 明确要求、观察和推断有来源，没有编造规则、题号或分值。 |
| 内容 | 回源读过公式、图和代码；数值、单位、假设与反例可复核。 |
| 逐页册 | 原页完整、顺序正确、解释对应，语言符合要求。 |
| 考场册 | 页数与语言均已确认；实质主题有去向，语言比例遵从所选英文为主/中文偏多/完整双语，英文保留结论条件。 |
| 派生材料 | 速查、易错与例题能定位到已核对来源。 |
| 编译 | 实际生成、重新打开每份 PDF，字体和后端可用。 |
| 视觉 | 最新 PDF 每页实际看过，无缺字、截断、重叠、坏公式或孤题。 |
| 打印 | 标准纸、可读字号、灰度清楚；目录、附录和术语页码准确。 |
| 版本 | 修正后重新检查，报告绑定实际交付版本。 |

完整模式另检查课程图与 JSON/Mermaid 源一致；模拟卷另检查可解性、答案、评分点和总分。仅做逐页册/考场册时不要求课程图或试卷套装。

自动格式校验不能评判教学质量。联系表可做全页扫描，复杂公式和密表应放大；自动核对不等于实际看过页面。

结论用 APPROVED、APPROVED_WITH_NOTES 或 REJECTED，注明范围、修正与限制，不承诺成绩。
