# 精讲与 Cheatsheet 的理工科讲义版式

适用于 `slide-walkthrough`、`exam-reference` 及 `study-pack` 的两册。正文仍以从零教学为目标；格式用于突出机制、数据与推理，不用装饰代替解释。用户提供的满意版式优先。

## 一页的组织

1. 上方完整嵌入原课件，保持比例、署名和原页码，周围用细浅灰边框。
   PDF 页面的旋转标记必须按实际显示处理；嵌入前在工作副本上归一化旋转并重新读取可见宽高，避免原页正常、合并后侧转或裁切。不要为归一化而改写用户原件。
2. 下方用简洁的青色标题点明这页要理解的内容，接一段中文引入。
3. 用 `1. …`、`2. …` 等具体小标题分解问题。正文、条目、表格和代码块按内容混排，不让每页都变成同样的名词列表。
4. 末尾用浅青底的“记住：…”提示框收束机制或易错边界，结论必须与本页相关。

## 优先用代码块表达的内容

- SQL、代码、伪代码、字段名、输入输出、日志、配置和数据样例。
- 分步骤的数据流、状态变化、二进制运算、短小计算推导；即使不是可执行程序，也可用 `text` 块表示。
- 块前说明它的作用；自编示例标明“自编”，伪代码不冒充可运行代码。块后解释输出含义、关键条件或容易误读之处。

```text
# 自编 XOR 恢复例；两位二进制，不是十进制
A = 10
B = 11
P = A XOR B = 01
丢失 B：A XOR P = 10 XOR 01 = 11
```

代码块保留缩进与换行；短字段在正文中用行内代码。英文、数字、运算符优先使用等宽字体，中文注释用中文字体回退。字体要嵌入；无中文等宽字体时不能因此产生方框。长代码重排、分块或合理换行，不裁切，也不无限缩字号。PDF 中应呈现真正的灰底代码框，不把 Markdown 的三个反引号原样打印出来。

不要强制每页放代码：纯概念、图片、行政页用适合的解释即可，也不要把普通中文段落整体改成等宽文本。

## 表格与提示框

字段 → 含义、事实值 → 解释、方案 → 条件/代价，以及逐步状态追踪，优先用带表头的表格。表头浅灰，行间细线，少用竖线；长文本允许换行，单位与符号保持完整。

代码框浅灰底、细灰边，四周约 10–12 pt 内边距；提示框浅青底、青色加粗结论。采用白色页面与深色正文，黑白打印仍能靠标题、框线和留白分辨结构；不要把截图的深色聊天界面当成 PDF 背景。

可参考配色与字号：正文 `#20262D`，强调 `#146B72`，线条 `#D9E1E3`，代码底 `#F1F3F4`，提示底 `#EAF5F4`。正文约 11–11.5 pt、行距约 17–18 pt；代码约 10–10.5 pt，优先保留阅读舒适度。它们是起点，不是不可调整的数值约束。

## 页高与检查

以下 cheatsheet 默认值适用于明确不限页的详细册。页数未明确先提问；一页改用 [紧凑型公式纸](compact-cheatsheet.md)，英文优先、仅个别繁琐处补中文，覆盖这里的双语长段落、单栏字号、宽松框体、完整问答与目录索引要求；两页公式纸也默认英文优先，在两页内压缩，不自动增页。逐页精讲的版式不受此规则影响。

Cheatsheet 同样使用灰底代码/伪代码块、细线对比表格、青色编号标题与“记住”提示框；在每个考点内仍按中文理解、具体例子/易错点、英文核心表述与英文短答的顺序组织。代码与数值推导采用等宽排版，整段英文答案仍用正常正文字体。目录、概念编号、原页映射与英文术语索引要能定位到实际印刷页。

Cheatsheet 的正文可从 10.5–11.5 pt 起步，保持固定 A4/Letter 页高，按内容自然接续考点。标题、出处与起始解释绑定；问题和答案绑定；结尾提示框不要单独落到下一页。不会因为要灰底代码框而缩小字号、丢掉条件，或把学习册的长页直接拿来打印。

屏幕精讲册使用固定页宽、按内容增长的竖页，以保留“一张原课件 + 完整讲解”同页。明确说明长页不是标准 A4 打印页；用户要求标准纸张时按规定分页并保留关联。考场册继续用标准纸张，不继承长页设置。

重开并渲染检查代码缩进、中文回退、表头、单元格换行、提示框与页脚；确认代码没有截断，正文没有遗漏，原课件边缘和署名完整。格式调整后重新查看实际成品，不能只检查源稿中的代码围栏。
