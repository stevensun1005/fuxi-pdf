# 来源与公开版整理

本项目用一个技能入口组织逐页教学、来源核验与打印考场资料。学习册和考场册采用不同语言结构。

- [final-review-slides](https://github.com/chowkayee11/final-review-slides)：复习完整性与证据流程的思路。2026-10-19 查阅快照没有 LICENSE；公开版不分发其复制文件。覆盖脚本、简洁 LaTeX 起点和对应的结构/核验说明由本项目重新编写。
- [NovaForge](https://github.com/SiriusFzh/NovaForge)：七步教学与模板素材。`assets/latex/`、`assets/typst/`、`assets/markdown/` 保留其模板和注释，依据 MIT 分发；原文见 [NovaForge-LICENSE.txt](../licenses/NovaForge-LICENSE.txt)。
- [summarize-slides-skill](https://github.com/Li-Baichuan-James/summarize-slides-skill)：全局阅读、自然主题分段与逐点回源的思路。MIT 署名见 [summarize-slides-LICENSE.txt](../licenses/summarize-slides-LICENSE.txt)。

`SKILL.md` 统一模式；`references/` 按需读取；覆盖校验是独立标准库实现，可用 inventory 发现整页漏记。

演示为原创数学素材，展示格式和机制，不使用学校课件或个人笔记，也不证明对任意课程能自动给出正确答案。

原创部分采用根目录 [MIT License](../LICENSE)；第三方模板保留各自署名。字体文件不随仓库分发。生成课程资料时应保留原材料署名并按其使用条件处理。
