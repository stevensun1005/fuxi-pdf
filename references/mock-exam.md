# 练习卷证据与作答检查

仅在用户要求，或完整复习包且已有足够考核资料时生成模拟卷；cheatsheet 请求不扩张为试卷套装。

先写 `mock-exam-blueprint.md`：范围、证据、题型、概念、难度与分值。没有官方时长/权重时标为练习设计。没有真题时写自编，不伪造学校、年份或题号。

出题后独立解答：条件是否充足，图表与数值是否相符，单选是否唯一，分值总和是否正确，题量与时间是否匹配。

题目 PDF 留作答空间，不放答案或泄题出处。答案 PDF 写推理、关键步骤、评分点建议、错误与紧密来源；说明其他解法的成立条件，不冒充官方评分。

题目和答案都实际编译、重开并逐页查看；编号、符号、子问题与总分须对应。未决问题保留在蓝图中，不虚报完成。
