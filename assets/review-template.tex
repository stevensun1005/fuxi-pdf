\section*{复习资料 / Study reference}
\textbf{中文理解：}局部平均值不能直接平均，除非组大小相同或正确加权。
保留总和与数量，合并后最后除一次。
\[
(s_1,c_1)\oplus(s_2,c_2)=(s_1+s_2,c_1+c_2),\qquad \bar{x}=s/c\ (c>0).
\]
\textbf{English answer:} Preserve the sum and count for each group. Merge both
components and divide only after aggregation, so that observation weights are retained.
