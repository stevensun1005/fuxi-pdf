# 一页 Cheatsheet：紧凑型公式纸

可参考仓库中独立的 [线性代数单页真实示例](../examples/compact-math/README.md)：约半学期主题、四栏三色，含 PDF、可编辑源稿、来源清单和压缩范围记录。详细考场册的多页演示不作为单页密度模板。

仅在用户明确选择一页，或主动指定这种紧凑风格时使用。没有明确页数或语言偏好先按 SKILL.md 提问，两项都缺时一起问；不从参考文件猜页数或语言。此风格来自用户认可的横向、多栏、三色公式纸；只复用通用排版，不复制私人课程内容、姓名、文件或考试规定。

## 页面与密度

- 一页就是一个标准纸张 PDF 页面，不暗加背面、续页或附录。参考风格虽可用于双面纸，一页请求仍只输出一面。
- 默认横向 Letter 或 A4；纸张有要求时遵从要求。以约 3.5–5 mm 窄边距、3–4 栏、细竖分隔线起步，公式密集时倾向四栏；按内容选择，不机械固定栏数。若已知打印机可打印区域，边距不得小于该范围。
- 页顶仅用紧凑的课程/范围/缩写说明。按章节或题型连续排布，用短编号、黑色粗体小标题、细横线区隔；不留封面、大标题区、独立目录、索引或大块留白。简短来源标记与完整可编辑台账分开保留。
- 紧凑单页默认不设底部页脚或长篇打印说明；必要署名与许可压成页顶一行，其余来源和打印设置放随附说明。腾出的面积优先补充公式条件、解题步骤、短例与易错辨析；保留一页，不靠裁切或遗漏条件增加密度。
- 先按主题分配栏高，再排公式与条件、区别与陷阱、解题步骤、必要短例。优先删重复和长解释；不要靠无限缩字塞进全部资料。正文约 7–9 pt 可作试排起点，不是强制字号下限；须以实际打印尺寸检查公式上下标和中文是否可辨。

## 黑蓝红三色与内容结构

先应用已确认的语言选择。以下英文为主写法对应当前公开示例；若选中文偏多，用中文解释机制与步骤并保留英文术语；若选完整双语，在明确页限内安排两种语言。不把示例的英文比例当成所有人的默认。

- 黑色：英文标题、解释、符号含义、前提与判断步骤；中文只作少量难点注释。
- 蓝色：核心公式、标准定义、英文答题句型与可直接替换的表达。
- 红色：少量关键限制、易错符号、禁用条件或必须记住的反例。颜色只辅助检索，仍用粗体、符号或标签保证灰度打印可区分。
- **选择英文为主时**：每个知识点采用“英文名称 → 公式/结论 → 英文条件、步骤与答题提示”。仅个别繁琐机制或易混区别补中文短注；不要每点中英复述、强制先中文后英文或逐句对译。即使还有空间，也优先补实用公式、条件、方法或例子，不补重复译文。中文偏多或完整双语版按所选语言组织；不限页本身不强制双语。
- 公式使用真正的数学排版，定义陌生符号，保留分母、自由度、单位、适用条件及边界；不能以 ASCII 拼图、裁切或省掉条件换取密度。
- 数据流、代码和算法采用短小等宽块；减少背景、内边距和装饰，不把详细册的宽松代码框与提示框硬塞进单页。比较关系用紧凑小表格。
- 英文句型可用清楚的占位符，例如 `Holding other variables fixed, ...`；不得将不完整模板当作具体题目的完整答案。

## 限页取舍与检查

覆盖全考试范围的主题结构，再分配空间；完整台账保留在源文件中。一页无法容纳全部细节时，优先保留有依据的重点、关键条件与高价值步骤，明确说明压缩范围，不声称所有细节都在单页，也不擅自增页。

重新打开并确认恰好一页、标准纸张、字体嵌入；逐栏放大检查公式、上下标、换栏次序、分隔线、溢出及中英文缺字，再查看整页与灰度效果。按实际大小打印或等效检查实际字号，避免只看放大截图。交付说明纸型、横向、100% 实际大小、每面一页；不能让打印软件再把多页缩到一面。
