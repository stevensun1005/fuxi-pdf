# 成品组织约定

## 两册流程

`study-pack`、`slide-walkthrough` 与 `exam-reference` 使用 [study-and-exam-pack.md](study-and-exam-pack.md)。按请求交付一册或两册，不额外扩张三册套装。

## 完整复习包

`final-review` 先说明范围与考试证据，再给课程地图、按讲次和原页顺序的章节、章节回顾与跨主题检索。重要概念解释定义、目的、机制、假设、例子、边界及来源，不只列标题。

课程地图以 `course-map.json` 为结构源，导出 Mermaid 或本地图；表现形式须一致。

`quick-reference` 便于查找定义、符号、条件、公式或框架、用途与来源。人文课程可用论点、案例或比较表替代公式。

`mistakes-and-distinctions` 汇集概念混淆、错误捷径、反例与诊断问题，不编造错误频率。

## 练习卷

题目册只给作答信息，不放答案或泄题引用。答案另册，写推导、关键步骤、可能评分点、常见错误与来源。自编时长/分值标为设计假设；真题年份/题号须核实。

## 覆盖报告

`coverage.csv` 字段见 SKILL.md。`coverage-report.md` 汇总来源与顺序、真实页数、逐页去向、重点定位、排除理由、引用核验、内容修正、编译与视觉检查及未决问题。

每份交付 PDF 单独记录结果。模板编译、CSV 校验、文字匹配和实际视觉检查不能互相代替。
