# 考试证据与重点选择

先区分“考试覆盖什么”与“知识点如何解释”。考试公告和 syllabus 决定范围、时长与资料规则；教师复习页提供强调；讲义提供定义、图、公式及顺序；作业和真题说明练习过的技能，不保证下次仍这样考。

- **Explicit**：教师或考试材料直接点名，附其来源位置。
- **Observed**：已提供的题目反复练习该技能，列出具体题号。
- **Inferred**：整理者依据概念依赖或机制做的选择，明确只是推断。

没有真题就不写“历年高频”，没有考试规则就不写“不限页”。说法冲突时保留来源位置并解释取舍，不用推测填空。

重点选择不能掩盖未处理的实质主题。精讲按原顺序保留每页；考场册允许合并重复内容，以台账记录每张源页对应的考点。
