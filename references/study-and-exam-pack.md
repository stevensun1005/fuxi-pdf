# 逐页精讲与可打印考场资料

推荐的两种成品风格。请求“准备复习 PDF 和 cheatsheet”或明确需要学习与考场两册时采用这套组合；只请求其中一种时只做那一种。明确的语言、版式、页数与考试规定优先，不把以下偏好强加给其他任务。

## 选择成品

| 意图 | 模式 | 成品 |
| --- | --- | --- |
| 两种都要、从零复习并准备考场查阅资料 | `study-pack` | `slide-walkthrough.pdf` 与 `exam-reference.pdf`，各自可编辑源文件，共用来源台账 |
| 每页课件都解释、上面原课件下面讲解 | `slide-walkthrough` | 完整逐页中文精讲 PDF |
| 打印带进考场、详细 cheatsheet、重点复习册 | `exam-reference` | 按考点整理的打印 PDF，先中文机制，再英文答题表述 |

Cheatsheet 不默认等于一张纸。已知页数、纸张或单双面限制时按限制设计；未提供时不声称考试允许不限页，也不为此阻塞可读稿的制作。明确要求“一页/两页/极简”时压缩为限页速查，不能套用不限页详细册。

## 共同工作流

1. 清点全部来源、讲次与真实页数，复用已有可靠提取文本、逐页笔记和渲染图，保持原页映射；不能只看旧总结。先建立全范围主题结构，再分段写作。
2. 对照考试公告确定范围、题型、纸质资料规则与答题语言。区分教师明确要求、题目证据与整理者推断；不预测分值，不把自编问答冒充真题或官方答案。
3. 按讲次与原页顺序写精讲；再从已核对的精讲中提炼考点册，合并重复而不丢掉独有机制、条件和例子。即使只做考点册，也要给每个源页登记去向。
4. 公式、图示、伪代码、数值和例子要回到原页核对。尤其逐条读箭头、对应关系、分组与边界，不只凭标题或算子名称推断执行方式。
5. 旧笔记与原页冲突时，以原页证据校正新稿，并记录受影响页码与勘误。未实际重编的旧 PDF 不宣称已修复。后续使用最新内容与页码，避免向用户交付多个难以区分的“最终版”。

## A. 逐页中文精讲：像面对面讲解课件

排版采用 [walkthrough-style.md](walkthrough-style.md) 的理工科讲义风格：青色标题、清晰编号、灰底代码或伪代码块、细线表格与浅青提示框。适合代码、字段、输入输出、计算和数据流的内容优先这样呈现，不把普通解释整段代码化。

- 每张原课件对应一张竖版成品页，上方放完整原页，下方是该页的解释。优先嵌入原 PDF，保持比例、署名、图例和边缘内容，不裁掉原图来腾位置。
- 按源页顺序保留所有页，包括重复、封面、行政和结束图片；此模式的“每页”不能因台账标为行政或重复就省去成品页。非技术页简述用途，重复页说明承接关系，不凭空编造新知识。
- 默认中文教学，仅保留必要英文术语、变量和代码，不再整段附英文复述。考场册的英文需求不能自动扩散到精讲册。
- 开头直接说明“这页在讲什么、为什么要讲”。用针对内容的小标题分解每个点，说明含义、具体机制与条件，再用小例子、对照表、步骤或代码框解释，结尾给简短记忆提示。
- 深度以没上过课的读者能理解为准：图中的框和箭头怎样连接、代码的输入输出是什么、公式每步怎样得到、为什么某方案成立，都需要解释。避免每页套同样的三段空泛概述或只翻译条目。
- 用具体例子区分容易混淆的动作，如“发现问题”与“处理问题”；数值推导写单位、变量和假设；概念解释同时给适用边界或小反例。补充例子注明自编，不能说成课件原例。
- 屏幕阅读可在固定页宽上按内容加长竖页，以维持一张原页与完整讲解同页；须说明页高可能不标准。若用户要标准纸打印，改用标准尺寸、必要时接续解释，并清楚保留原页关联。不要缩成小字，也不要把屏幕长页直接当成打印册。
- 页眉或页脚标来源讲次、原页码、成品页码，提供讲次与逐页书签，能从解释回到原课件。

## B. 考场重点册：中文理解，英文作答

同样采用 [理工科讲义版式](walkthrough-style.md)：代码/伪代码和计算过程用灰底等宽框，方案、字段与状态用对比表格，编号标题与提示框帮助检索；中文之后仍给自然英文表述与短答。考场册使用固定纸张，不能照搬逐页精讲的长页尺寸。

与逐页精讲分开编写，不是删掉图片后的缩略版，也不是把中文全文复制翻译一遍。按概念和取舍集中整理，通常不再放全部原幻灯片，以免增加纸量而降低检索效率。

每个重要考点按此顺序组织，按课程性质调整小标题：

1. **中文理解**：是什么、解决什么问题、如何工作、成立条件和主要代价。详细请求要讲机制和推理，不用名词列表代替教学。
2. **具体例子**：手算、流程、代码或比较表；必要时加入反例，解释为何一个看似合理的捷径不成立。
3. **易错点**：容易混淆的语义、前提、单位、粒度、类型或因果判断。
4. **英文核心表述**：自然、准确、可按题意取用的英文段落；保留中文中影响结论的条件与限制，不机械逐句翻译。
5. **英文概念题短答**：详细册通常配两种有区别的问法，例如定义/解释、比较/选择、为什么/反例。答案先直接回答，再说明机制与条件，通常 2–4 句；按实际题型调整，不用泛泛套话填充。
6. **定位**：来源讲次与真实页码、稳定考点编号；跨页时重复编号，让英文答案脱离上一页也能定位。

考场册应覆盖全部范围的实质主题，不因“重点”只保留前半本或熟悉的章节。重复讲次可以用新的比较角度复盘；被合并的源页在台账中指向同一考点。

按需要加入实用速查附录：方案选择及前提、公式/符号/单位与推导例、易混概念对比、英文题目动词与简答组织方法。提供印刷目录（考点起止页以及附录位置）、PDF 书签和按英文排序的术语索引；索引指向成品页码，不冒充源页码。

### 打印版式

- 用标准纸张与固定页高。优先用户/考试规定；未指定时按地区选 Letter 或 A4，并在交付时说明。不要沿用逐页屏幕册的可变长页。
- 单栏、黑色正文、浅灰框线；只在有教学价值时放图表，黑白打印仍需清楚。正文约 10.5–11.5 pt 可作起点，优先增页而不是不断缩字。
- 控制无意义留白；可以同页接续考点，用标题、分隔线和编号保持检索。讲次边界、复杂图表和用户指定的一页一主题可优先分页，不硬塞成一张纸。
- 标题与其正文绑定，英文小标题不能孤立在页底；表格列宽与对齐要适合长术语。若把短英文块放入不可拆容器，内部不要再嵌可分页框，避免多余空行或内部边框；较长内容应允许自然接续。
- 稳定目录、页码和交叉引用后再检查；核对每个索引实际指向的主题。给出实际大小/缩放、每面页数、双面翻转方向和纸张数量，数量按成品页数计算。

## 核验与交付

- 先验内容，再验版式。独立复算代表性数值和反例；核对图的每侧依赖、状态/类型闭合、重复与边界等影响结论的细节。适合且获准委派时由不同写作者交叉复核，否则分开进行回源复核。
- 比对真实源页集合与 `coverage.csv`，不仅运行格式校验。精讲检查原页与成品逐页对应；重点册检查源页到考点、考点到印刷页的映射。
- 重新打开成品检查纸张、字体嵌入、正文与页码完整性；可自动核对结构化稿中的文字/表格/英文短答是否落入 PDF。渲染并实际查看全部成品页，联系表做全覆盖，密集或可疑页再放大；自动检查不能代替视觉检查。
- 核对的是最新重编版本。实质内容或排版修改后重新检查受影响内容、目录与布局，保留检查范围或文件哈希，不能把旧版审核当成新版审核。
- 保留可编辑源文件、结构化内容或页码映射、覆盖台账与核验结论。不固定课程名、页数、考点数、字体路径、个人目录或某一届考试规则。
- 两册都请求时分别交付两个明确命名的 PDF；只请求其中一册则只交付那一册。最终简述范围、语言组织与实际核验结果，打印册附实际打印设置，不承诺满分或全部考试内容。
